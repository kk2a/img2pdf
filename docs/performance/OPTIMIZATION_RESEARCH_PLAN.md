# ImageToPdf 最適化調査計画

作成日: 2026-04-10  
対象ブランチ: main

## 1. 目的

本資料は、Rust版 ImageToPdf の実行速度と出力容量を改善するための調査計画書。
実験結果の記録欄は空欄で残し、比較しやすい形で運用する。

### 目標

- 実行時間を短縮する
- 画質を維持したまま PDF 容量を削減する
- 変更の副作用を把握し、安全に段階導入する

---

## 2. 計測方針

### 固定条件

- 入力データセットを固定する
- 実行マシンを固定する
- release ビルドで計測する
- 1ケース 3回以上実行して中央値を使う

### 推奨指標

- 総実行時間 (秒)
- Processing フェーズ時間 (秒)
- Saving フェーズ時間 (秒)
- 出力 PDF サイズ (MB)
- ピークメモリ使用量 (任意)

### 実行コマンド例

cargo run --release "<input_folder>" "<output_pdf>"

## 6. 採用判定ルール

- 採用:
  - 速度または容量で有意改善がある
  - 品質要件を満たす
  - 実装複雑度が許容範囲

- 保留:
  - 改善はあるが副作用が無視できない

- 却下:
  - 改善なし、または劣化
