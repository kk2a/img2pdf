# Agent向け実行指示書: 速度最適化

作成日: 2026-04-10  
対象リポジトリ: img2pdf  
対象ブランチ: enhance/speed

## 1. 目的

Rust版 ImageToPdf の実行速度を改善する。
画質劣化を避けつつ、段階的に改善施策を適用する。

## 2. 前提・制約

- A-1 (JPEG 可逆最適化) は却下済み
- A-2 (並列度チューニング) は却下済み
- 既存の機能互換性を維持する
- 変更は小さい単位で分ける
- 各施策ごとに計測可能な状態で終える

## 3. 実施対象施策

### 施策1: A-3 進捗更新オーバーヘッド最小化

狙い:
- 進捗通知と表示更新コストを削減し、CPUワークの阻害を減らす

実装候補:
- 進捗通知の間引き (例: N件ごと、または一定時間ごと)
- CLI進捗バー更新のフラッシュ頻度低減
- 不要なスレッド間通知の削減

対象ファイル:
- src/image_processor.rs
- src/cli.rs

完了条件:
- 進捗表示は維持
- 実行時間が悪化しない

### 施策2: B-2 I/O パス最適化

狙い:
- 一時ファイル作成、読み書き、配置順序の無駄を減らす

実装候補:
- 一時ファイルの作成/削除回数最適化
- ファイルI/Oの失敗時フォールバックの効率化
- 不要コピーの削減

対象ファイル:
- src/image_processor.rs

完了条件:
- 出力内容が同一
- Saving フェーズ時間が悪化しない

### 施策3: B-1 リサイズ処理の比較検証 (品質維持前提)

狙い:
- 入力タイプ別に処理速度の良い方式を見つける

実装候補:
- リサイズフィルタを設定化し、比較実験しやすくする
- デフォルトは現行維持

対象ファイル:
- src/image_processor.rs
- src/utils/constants.rs (必要時)

完了条件:
- 画質要件を満たす
- 比較可能なログを残せる

## 4. 非対象

- PDFライブラリ移行 (C-1) の本格実装
- GUI仕様変更
- 大規模リファクタ
